# Ciphers Through Civilizations — شفرات الحضارات

لعبة ويب تعليمية مستقلة صُممت لكلية الحاسب في جامعة فهد بن سلطان، لتقديم رحلة تاريخية تفاعلية عبر خمسة محطات في علم التشفير وتحليل الشفرات.

## التشغيل

لا يلزم تثبيت أي حزم أو اتصال إنترنت. افتح `index.html` في متصفح حديث (Chrome أو Edge أو Firefox) لتبدأ.

## المحتوى

- خمس تحديات تعمل فعليًا: Scytale، Caesar، تحليل التكرار لدى الكندي، Vigenère، ومحاكاة Enigma تعليمية مبسطة.
- نقاط، عداد وقت، تلميحات، إيقاف مؤقت، فتح متسلسل للمستويات، ولوحة متصدرين محلية عبر LocalStorage.
- شهادة قابلة للطباعة من شاشة الفوز.
- واجهة عربية RTL مع نصوص التشفير LTR، وتصميم متجاوب لسطح المكتب والجوال.

## ملاحظة العرض

لا توجد صور أو مكتبات أو خدمات خارجية مطلوبة. تستخدم اللعبة رموزًا ونقوشًا CSS/Unicode وخطوط النظام المضمّنة؛ وبالتالي تعمل محليًا بالكامل دون اتصال.
